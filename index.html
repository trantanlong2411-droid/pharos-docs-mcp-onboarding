Documentation gaps & proposed fixes

1Unclear Docs MCP discovery and recovery

Session 1 showed no MCP tools and a denied diagnostic command; session 2 connected successfully. No clear recovery workflow was provided to the user.

Fix: show connection status, expected tools and approved recovery steps. Session-scoped incident, not universal outage.

2No relevant AI.PHAROS Docs MCP onboarding result

The focused search surfaced Chain MCP / Anvita Flow guides rather than a tutorial for Docs MCP inside AI.PHAROS.

Fix: publish and rank an AI.PHAROS-specific Docs MCP onboarding guide with UI steps and an initial sample query.

3Hardhat network setup omitted from the tutorial

The official guide calls --network pharos but does not explain the network definition. The official example config uses an RPC URL placeholder.

Fix: link the config file, explain network selection, RPC placeholder, chain ID and testnet accounts before deployment.

4Missing versions and Windows-specific steps

The guide does not provide a validated Node.js/Hardhat version matrix or PowerShell instructions.

Fix: publish tested versions and a Windows setup/troubleshooting section.

5Unspecified ethers version and wallet prerequisites

The frontend snippet uses ethers.providers.Web3Provider (v5 API) but does not explicitly pin a compatible ethers version or explain the browser wallet prerequisites.

Fix: pin ethers v5 or update for v6 BrowserProvider; document wallet connection.

Each gap refers to the exact session prompts shown above or in the full README. Additional issues documented there include unclear frontend directory and missing faucet reference. Search not finding a page is not proof of global nonexistence.
